# Tiles

- `mount-vernon/tileset.json` — LOD2 3D Tiles index (bootstrap from footprints).
- GLB content tiles (`b_*.glb`) are generated by `pipeline/build_lod2_tiles.py` and ship in the full download zip (`Auto-3D-City-Builder-Mount-Vernon.zip`).
- `pointcloud/` — Ohio River sample point layer (JSON + regenerate `.bin` via pipeline).

Regenerate LOD2 GLBs:

```bash
python3 pipeline/build_lod2_tiles.py
```
