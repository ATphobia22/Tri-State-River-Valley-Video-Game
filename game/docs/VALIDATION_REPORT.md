# River Valley — Family Game v1.1 validation report

Tested on November 21, 2026 in a Linux-based isolated build container.
The work is **independent of all user's repositories**; no GitHub changes, public deployments, or connected cloud storage mutations were made.

| Gate | Outcome | Evidence and limitations |
|---|---|---|
| Game-core unit suite | **PASS 15/15** | `node --test tests/test-core.cjs`; includes position bounds, one-time rewards, save validation, DEM sampling, farm lifecycle, affordable and unaffordable cottage construction. |
| JavaScript parsing | **PASS** | `node --check src/core.js` and `node --check src/game.js`. |
| Desktop browser 2D smoke | **PASS** | Chromium Playwright `tests/browser_smoke.py`: starts game, reads 4,429 buildings and 719 road lines, atlas, collect discovery, farm sowing, cottage construction, settings, local save with test storage. |
| Mobile touch smoke | **PASS** | Chromium 390x844 emulated touchscreen `tests/mobile_smoke.py`: starts offline HTML, reveals virtual controls, 2D atlas, changes to driving. This is browser emulation, not actual iOS device testing. |
| Single-file offline packaging | **PASS static** | `python build_offline.py` incorporates scripts, Three.js, and geographic data; no external script `src` or required HTTP requests. Browser behavior depends on the platform's local-file restrictions. |
| 3D WebGL rendering | **UNVERIFIED** | This container's Chromium failed WebGL context creation (`BindToCurrentSequence failed`); game's 2D fallback ran. Real GPU capture, render performance, visual collision and 3D controls must be verified on device. |
| iOS Safari and Windows browsers | **NOT TESTED ON DEVICE** | Mobile Chromium emulation is not an iPhone. Opening local HTML may be blocked by Files preview apps. |
| Unity native player | **NOT BUILT** | Optional Unity folder contains data and Editor terrain importer only; no Unity Editor, Windows standalone build or iOS build was available for testing. |
| Geography and rights | **PROTOTYPE ONLY** | Original user-provided 200x200 DEM has 8.4% infill and an unverified datum; derived footprints and OSM-derived roads require attribution/licensing review for public distribution. River drawing and POI gameplay offsets are illustrative. |
| Media teaser | **PASS metadata** | `docs/River_Valley_Game_Teaser.mp4` is a 7s H.264 1280x720 24fps still-screenshot UI teaser; verified with `ffprobe`. This is not a recording of GPU-verified 3D gameplay. |

**Follow-up acceptance gates:** WebGL hardware rendering in Windows browser, actual iPhone browser behavior, input and collision QA on target devices, long-run game testing, audio/accessibility review, and native Unity compilation only if a Unity project is intentionally created.


### November 21, 2026 — v1.1 addendum
- Gameplay-core tests: 15/15 passed, including legacy save migration, hunting aim window, fishing reaction timing, cooking pantry deductions, and farm inventory.
- Interactive desktop/mobile Chromium test: `tests/activities_smoke.py` confirmed all 12 checks (hunt success, fish catch, crop harvest, recipe availability, cooking success, local storage save across both desktop and mobile viewport simulations), with zero uncaught errors.
- Standalone HTML regenerated by `build_offline.py` with no external assets referenced for gameplay.
- Base44 web application built and deployed to its own published website with inline standalone game under `/game.html`. Public text retrieval confirmed both homepage and game page returned the expected content. User-device launch and actual Safari video playback are still not independently verified.
- H.264 teaser is served from Base44 media; it displays prior v1 UI screenshots and is not proof of 3D rendering.
